# Fibonacci task

## How to compile 

> Note: Clang 17 or newer is needed for this or any other compiler that supports c++23
### Linux, MacOS
#### Step 1.
```bash
clang++ ./main.cpp -std=c++23      
```

#### Step 2.
```bash
./a.out
```

### Windows
#### Step 1.
```bash
clang++ ./main.cpp -std=c++23      
```

#### Step 2.
Powershell:
```bash
./a.exe
```

CMD:
```bash
.\a.exe
```
